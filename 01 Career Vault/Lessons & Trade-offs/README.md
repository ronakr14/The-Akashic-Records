# Lessons & Trade-offs

> Experience-derived wisdom. "If I could go back, I'd..."

## Why separate lessons from reference?

Reference tells you *how something works*. Lessons tell you *what it feels like to use it wrong*. The latter is harder to find elsewhere and compounds faster.

## Format

```markdown
# [Lesson Title]

**Date:** YYYY-MM-DD
**Domain:** [e.g., data pipelines, system design, career]
**Source:** [What project/experience this came from]

## The Situation
What happened?

## The Lesson
What I'd do differently.

## Why It Matters
When does this lesson apply? What's the pattern?

## See Also
- [[related-note]]
```
