# AI Summary
Reusable end-of-session template that instructs an AI or contributor to generate a handoff document before ending work. The handoff should capture the project goal, repository status, files being edited, unsuccessful attempts, and recommended next steps to enable seamless continuation in a future session. Also references related workflows for extracting feedback and updating a daily note.

---
Before we end this session, write a `handoff.md` file that captures:

- the goal we're working toward
- current state of the repo
- files you're actively editing
- everything you've tried that failed
- the next step you'd take
